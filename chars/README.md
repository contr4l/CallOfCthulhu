# 官方角色模板

本次核查对应 `scripts` 中的《Alone Against the Flames》和《静躁独行》（Alone Against the Static），核查日期为 2026-10-08。

| 剧本                     | 官方建卡方式                                     | 本地内容                                                                      |
| ------------------------ | ------------------------------------------------ | ----------------------------------------------------------------------------- |
| 静躁独行                 | 两名预设调查员 Alex（销售人员）、Charlie（护士） | `alone-against-static/alex.json`、`charlie.json`，以及 `sources` 中的官方 PDF |
| Alone Against the Flames | 在冒险中逐步创建调查员，官方附空白卡             | `alone-against-flames/manifest.json` 记录引导建卡方式，无固定人物模板         |

来源：[Chaosium 的 Static 产品页](https://www.chaosium.com/alone-against-the-static-pdf/)、[Chaosium 的 Flames 发布页](https://chaosium.itch.io/alone-against-the-flames)。Static 产品页提供两份角色 PDF；JSON 中保存原始下载地址、SHA-256 和来源日期。

属性及已分配技能通过 PDF 表单字段提取，并与渲染页面核对。未分配技能采用卡面印出的基础值；闪避为敏捷的一半，母语为教育值。生命、魔法与理智初值也与卡面核对。官方卡的幸运字段为空，按剧本说明由玩家在创建实例时点击掷 3D6×5。简介为简短中文转述，原始人物背景可查来源 PDF。

`manifest.json` 分组说明建卡方式并列出模板文件。模板由服务器读取；`npm run chars:validate` 校验结构、模板唯一性、来源 PDF 校验和及派生数值。添加模板时保持已有模板版本不变，修改内容应发布新的版本。

网页“调查员”页面可从模板创建保存角色，只允许修改名字，模板数值由服务器确定。玩家必须先点击“掷幸运骰”，观看三颗骰子的动画及结果，再确认创建；服务器保存该次点数，刷新或重试不会重掷。开局选择“已有调查员”会复制该角色，保留幸运。后续局内变化仅写入该局，原模板、保存角色与其他游戏进度互不修改。当前两份原作仍是导入材料，角色可先用于可玩的原创示例剧本。
