固定版本：`4cb8fa2f081cb031825afbe4dbc8a8a5dcb294dc`。

`source/chapters` 保存 263 个原始 JSON 章节，文件字节未修改。`source/chapter-map.js` 保存选项与目标章节映射，`source/script.js` 和 `source/coc-server.js` 保存来源的客户端／服务端逻辑，供后续理解规则。来源代码只下载保存，未执行。`source-manifest.json` 记录下载地址、字节数、Git blob SHA-1 与 SHA-256。

章节 JSON 的 `texts` 是带 HTML 的文本片段，并不总是一项一个自然段；其 `options` 中的 `key` 是选项编号，目标章节在单独的 chapter-map.js 中。后续转换必须结合这些文件处理条件和检定，不能仅根据 options.key 生成跳转。

相对英文 EPUB 的 270 个编号，缺少 **2、12、20、187、241、247、268**。跳转映射还引用了缺失的 2、12、241、247、268。未补译或删掉这些引用。静态编号与关系对比见 `comparison.json`；这并非已经验证的完整中文可游玩剧本。未替换现有英文关系图及原文片段。

另有原文件格式问题：`235.json` 与 `262.json` 仅含 `//TODO`，没有正文，无法按标准 JSON 解析。原始字节已保留，后续转换需审校，不能把它们直接交给 JSON 解析器。

## 英文原版补译后的完整章节集

`chapters/` 为完整的 270 个中文编号章节，沿用来源的 `key`、`texts`、`options` 格式及 `[guide-start]` / `[guide-end]` 标记。原有 261 个正文文件逐字节复制；**2、12、20、187、235、241、247、262、268** 根据本项目的英文 EPUB 原文片段补译。原下载文件留在 `source/`，没有覆盖。

根目录的 `chapter-map.js` 是补全映射，新增缺失的章节记录并保留原映射；235、262 的选项编号与原映射一致。187 使用来源已有的困难侦查检定格式。新章节的耐久恢复与技能打勾保留为规则指令，235、262 的战斗需要依照正文规则处理，未实现自动战斗。

`translation-manifest.json` 记录英文原文路径、译文校验和及审校说明。英文原件中的第262段没有给出逃跑时困难检定的技能名称，因此译文没有擅自指定；第268段的孤立数字 `1` 也保留，没有凭空补上通往20的选项。第20段和部分隐藏段落的可达性仍需原作规则审校，文件齐全并不等于所有规则已经自动运行。

`completion-report.json` 确认 270 个 JSON 章节全部有效、映射没有缺失目标，261 个已有章节与原下载字节一致。之前的 `comparison.json` 描述原下载版本的缺损情况，不代表补全版仍有这些文件缺失。
