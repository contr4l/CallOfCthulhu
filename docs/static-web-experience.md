# 《静躁独行》网页内体验

剧本馆开放《静躁独行》。新局默认使用 1.2.0；1.0.0、1.1.0 内容包和旧存档保留，规则与角色数值不覆盖。

## 角色与正文

开局选择亚历克斯或查理，使用已经核对的官方角色模板，属性和技能固定。新角色须先掷 3D6 幸运骰，幸运为点数和乘以 5。已有调查员只展示这两种模板的角色，保留既有幸运并复制为独立局内角色；其他模组的角色不会误选入本局。

新版保留 372 个原书条目和 5 个规则辅助节点。中文正文从 `scripts/静躁独行.txt` 恢复，合并排版造成的句中断行，保留自然段与对白。编号跳转、记录表打勾、返回条目提示以及已经由服务器执行的骰子修正说明从正文剥离；TXT 原件保持完整。

局内角色记录、着凉、衣着、探索、磁带与其他剧情状态自动登记。唯一合法行动显示“下一节”；实际剧情选择与孤注一掷仍由玩家决定。检定、理智与生命变化以及重伤／疯狂的中断返回继续使用已审校的 1.0.0 规则。

简繁转换、字号、字体、文字动画、骰子演出、刷新恢复、回忆和回放复用《向火独行》的通用组件。当前只有中文来源，英文选项保持禁用，不生成伪造英文原文。

## 结局和存档

14 个结局保留原条目 ID，独立收集并解锁成就。中文显示名根据对应正文编写，仅为网页适配名称，并非原书官方标题。结局名在抵达之前不透露。

1.0.0 保留兼容正文语言包，1.1.0、1.2.0 的正文与中文语言内容存入独立片段；读旧局和回忆时提供对应中文文本，不改变既有骰点、角色数值、规则或进度。

## 编译与验证

```sh
python3 tools/story/build_static.py
npm run story:validate
npm run typecheck
npm test
npx playwright test tests/browser/static.full.spec.ts --project=desktop --project=mobile
```

常规 `story:compile` 同样会生成新版《静躁独行》，并保留 1.0.0 发布包。1.1.0、1.2.0 已拆为 `coc-runtime-graph@1` 规则图和 `fragments/*.json` 正文文件；完整导入与发布规范见 [剧本工作流](story-workflow.md)。

`tests/static-experience.test.ts` 检查完整条目、源校验和、旧规则一致性、正文断行修复、双角色入口、条件检定、自动登记和独立结局。`tests/browser/static.full.spec.ts` 通过真实 React 操作和 API handlers 完成两名角色的生还路线以及一次体质失败后的生还路线，检查骰子窗口刷新恢复、结局收藏和成就。仅测试随机源受控，没有生产跳关接口或状态注入。

浏览器路线可通过 `npx tsx tools/story/build_static_routes.ts` 重建。代表性完整路线不等于穷举所有组合；原文的特殊规则解释仍保存在 `source.notes` 和单人模组实现说明中。

1.2.0 只调整两处退出操作：条目 57 返回 78、条目 66 返回 57 的选项可重复使用，调查项目仍只能使用一次。原文存在 76→75→66 的重返路径，旧实现会将已离开过的场景出口耗尽。修复不新增跳转、不改变角色和骰点；旧版本与旧局保留。全结局与持久化验证见 [本地测试报告](static-test-report.md)。

完整结局专项测试位于 `tests/static-endings.test.ts` 和 `tests/browser/static.endings.spec.ts`，覆盖两种角色各 14 个结局的认证 API 路线，以及每个结局的桌面／手机按钮流程。桌面弹窗主按钮取消悬停位移，避免特定指针位置下无法稳定点击。
