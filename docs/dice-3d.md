# 立体骰子

骰盘采用 [@3d-dice/dice-box-threejs](https://github.com/3d-dice/dice-box-threejs)，版本 0.0.12，MIT 授权。模型、数字面纹理由库在本地生成，Three.js 渲染，Cannon ES 模拟重力、碰撞、反弹和摩擦。不依赖外部模型或运行时 CDN。

- 支持 D4、D6、D8、D10、D12、D20。D100 使用两个十面骰，十位骰标记 00–90，个位骰标记 0–9，00 + 0 = 100。
- 剧情推进触发检定或规则骰后，等待玩家点击“掷骰”才播放立体翻滚并揭晓结果；刷新恢复时同样保留手动掷骰。
- 动画使用服务端已保存的点数指定落点；动画完成才揭晓结果，不额外请求随机数。剧情检定、规则骰和幸运骰共用骰盘。
- 简化动画和系统减少动态效果设置直接显示静止模型。
- 任意面数、超过 20 个实体骰、WebGL 不可用时显示数字骰点；保留原有结果保存和重试行为。
- 渲染器按需加载，离开骰盘时释放 RAF、尺寸观察器、纹理、几何体和 WebGL 上下文。

`DiceScene.ts` 对库的 resize、清理和动画回放方法做了生命周期适配，因为此版本未提供销毁 API。使用固定物理步长预先记录位置和旋转轨迹，在显示骰子前完成骰面编号。动画只插值回放已记录的轨迹，不再次计算物理、不在停稳时替换骰面；帧率变化不会改变落点。回放速度为 1.8 倍，预模拟设置 480 步限制。

验证：`tests/browser/dice-3d.spec.ts` 覆盖所有标准多面骰的最小/最大落点、D100 的 100 与 37、画面翻滚变化、桌面/手机宽度、静止模型和 WebGL 降级。另验证正常和低帧率下，从首个可见帧到停稳，骰面的几何、编号和材质均保持固定，最终画面不会再次改变。
