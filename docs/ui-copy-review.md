# UI 文案与信息层级精简

本次只调整展示和交互层级，保留正文、规则、骰点、存档、成就及道具机制。

| 条目        | 修改                                                                                           | 验证方式                                                  |
| ----------- | ---------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| 1. 骰子提示 | 删除“已保存、不会重掷”等重复保证；保留骰式、动画、点数和错误重试                               | 角色创建、骰子揭晓、刷新恢复和重掷浏览器流程              |
| 2. 建卡说明 | 移除底部重复说明，只留入口说明、必填字段和分配约束                                             | 全程建卡、已有调查员开局及分配流程                        |
| 3. 角色来源 | 来源、出版者和模板版本放入可展开详情；移除“示例角色”等过时称呼                                 | 桌面/手机展开来源、幸运骰按钮与角色创建                   |
| 4. 回忆档案 | 默认展示结局标题或已读正文预览；编号、阅读次数收进详情；数量和进度条不再附加未知数量说明       | 章节/结局切换、已读文本打开、未知结局保护及跨版本去重测试 |
| 5. 首页     | 删除重复口号、期号与英文栏目包装；保留游戏版本和一套档案编号；向火介绍改为来自开场剧情的短简介 | 桌面/手机截图、横向溢出、剧本入口、版本号                 |
| 6. 检定     | 主结果保留 D100、目标、骰点和成败颜色；特殊原因及多骰点放入“判定详情”                          | 全程检定、对抗、伤害、详情展开/收起、刷新与剧情推进       |
| 7. 成就     | 结局标题只展示一次；成就通知改为较小徽标，保留编号和入口                                       | 结局、成就领取和查看结局流程                              |
| 8. 辅助文案 | 精简商店的使用时机、设置提示和回放标注；删除“单向旅程/骰点不可撤回”等与玩法易冲突的说法        | 商店购买、道具使用、阅读设置、历史只读浏览                |

来源正文和审校资料保持原位。章节预览只从玩家已经看到的历史正文提取，不引入未知剧情；完整段落仍在阅读窗口中展示。游戏仍保存原骰点，重掷仍执行原有规则，检定细节只是默认收起。

验收通过：19 项相关单元/集成测试、46 项桌面/手机浏览器检查，以及使用正式剧本目录的4项展示复核。独立提交快照的类型检查与前后端构建通过。

新增的 `ui-copy.spec.ts` 验证来源详情可访问、角色创建控件可用、游戏版本可见及桌面/手机布局；既有完整路线用例继续验证核心游戏操作。骰子刷新测试等待服务端确认结果完成后再刷新，避免把尚未确认的结果当成已确认存档。只提供中文的剧本设置检查移到有真实解锁资格的 Static 测试环境中。
