# 当前两部单人模组

两个包均使用 `coc7-solo@2`。原始材料留在服务端，浏览器只接收当前正文、合法行动、检定信息、角色与已公开记录。未经历的分支、隐藏标记和执行程序不在 API 场景响应里。

| 模组              | 原书剧情条目 | 总节点（含规则辅助节点） | 建卡                                              |
| ----------------- | -----------: | -----------------------: | ------------------------------------------------- |
| 静躁独行          | 372（0–371） |                      377 | 官方 Alex / Charlie，固定属性与技能               |
| 向火独行（1.1.0） | 270（1–270） |                      282 | 剧情分配属性、五种职业、四项兴趣；条目 134 掷幸运 |

`tools/story/compile_solo.py` 从仓库的 TXT / EPUB 编译，常规指令提取后由明确的逐条覆盖表达特殊规则。每个节点保留 `sourceId`，剧本元数据保留源文件 SHA-256 和适配说明。TXT 末尾的角色表不计为故事条目。《向火独行》新局使用 1.1.0 中文完整版，正文取自仓库已补全的 270 个中文章节，选项与技能标签同步中文化。旧版 1.0.0 继续保留，已有局仍绑定原版本。

引擎执行数据指令，不执行剧本内的任意代码。支持数值与标记条件、物品、骰子效果、访问次数、一次性选项、循环探索、自动路由、强制检定、孤注一掷、属性检定、倍率与对抗检定、奖励与惩罚骰，以及随机选择未经历症状。静躁的重伤、临时与不定性疯狂可以中断当前段落，随后从保存的操作位置返回，避免再次扣除生命或理智。

Flames 支持探索次数、疲劳、秘密路径、书籍与仪式记录、魔法点与生命支付、技能成长标记，以及熊、骑手和工匠的战斗。战斗保存轮次与行动阶段，区分主动攻击、反击和闪避；熊每轮两次攻击、每轮护甲与三轮生存条件独立处理。检定与输入仍使用同一个事务、修订号和幂等命令协议，断线重试不会重新掷骰。回放展示保存的历史视图。

## 原文缺字与解释

- Flames 28、29 的 EPUB 缺失检定名称，按同版官方 PDF 补为 Natural World。29 在 DEX 与 SIZ 相等时采用 DEX 不低于 SIZ 的分支。
- Flames 262 逃脱检定在源文中缺失技能名，依据条目 12 的 Dodge 提示使用困难闪避。这是明确的适配解释。
- Flames 268 残缺的提问选项补至条目 20。
- Static 186 的强制磁带入口按每盘只强制一次解释，保留原记录标记；重伤阈值按中文原文的过半生命，疯狂采用单次损失至少 5 和当天累计五分之一。条目 34 重设当天基准。

这些说明也写入包内 `source.notes`，便于以后修订；已存在的存档继续绑定原版本，不应在发布后覆盖版本文件。

## 验证与边界

构建包含 TypeScript 校验。内容校验检查严格数据结构、节点引用、可达性、技能和资源；运行测试覆盖建卡分配、循环、疯狂返回、孤注一掷、施法、对抗、战斗、完整生还路线、命令重试，以及两个模组各 80 条带种子的完整随机路线。浏览器测试覆盖桌面和手机的建卡与恢复流程。

这套实现针对当前两个模组的规则需求，并非完整 CoC 规则书。尚未提供通用幸运消耗、任意职业和多人战斗；旧示例与旧存档继续使用 v1。成长在当前冒险中记录勾选，不附加原文未要求的后续成长阶段。

重新编译和校验：

```sh
python3 tools/story/compile_solo.py
npm run story:validate
npm run build
npm test
npm run test:e2e
```
