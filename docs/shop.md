# 余烬商店与结局奖励

这是可选的网页扩展规则 `web-shop@1`，不是原书规则。剧本正文、发布图和旧存档不改写；不使用道具时仍执行原检定。奖励档位和售价集中在 `packages/contracts/shop.ts`。

## 点数领取

结局成就解锁后，在成就页点击“领取点数”。同一账号、同一剧本的同一结局只能领取一次，不同内容版本共用结局身份。旧版本已经通关的记录也可以领取。不同账号各自结算。

初始奖励很少：默认结局1点、生还档2点、困难／特殊档3点。这里的“困难”是网页奖励配置，不宣称原书提供了结局难度等级；已审校的结局 ID 用于配置，未列出的结局默认1点。未解锁的结局不显示名称或奖励金额，避免泄露内容。

点数必须主动领取，不自动入账。尚未确认的检定所触发的结局不可领取；被重掷取代的结果不计入成就、章节收集或奖励。

## 剧本顺序解锁

《向火独行》免费开放，之后按《向火独行》→《静躁独行》→《潮汐独行》→《冰霜独行》→《恐惧独行》的顺序解锁。后四部均在商店支付3余烬点永久解锁，并要求前一部至少抵达一次已确认、可收藏的结局。任一此类结局均计入，包括死亡或疯狂结局；不要求获胜，也不要求三个不同结局。健康退场等 `collect: false` 结果、未确认或被重掷取代的结局不计资格。通关资格与是否领取奖励分开：点数仍须在成就页主动领取，购买时余额必须足够。

商店只列出已发布剧本，剧本馆显示对应前作和价格，点击锁定剧本进入商店。后端对购买和新开局同时检查权限，不能通过直接请求新局绕过。重复购买不会再次扣费，解锁保存到账户，刷新和服务重启后继续有效。已有任一剧本存档或解锁记录的账号保留该剧本访问权限，无需补交点数；拥有前作本身不算通关。解锁复用库存与购买表，不新增数据库版本，不改写剧本包、角色或原存档。

## 购买与使用

| 道具     | 售价 | 使用方式                                                                                     |
| -------- | ---- | -------------------------------------------------------------------------------------------- |
| 重掷券   | 3点  | 普通、非战斗且无对抗的 D100 结果揭晓后，点击“使用重掷券”；以新骰点为准，并不保证更好。       |
| 命运助力 | 2点  | 检定前勾选，目标值增加10、上限99；已达到99的检定拒绝使用。困难／极难检定在原目标计算后加10。 |

命运助力仅影响该次检定及它的重掷，不修改角色卡永久数值，也不影响对手骰点；重掷券不用于战斗、对抗、幸运生成、伤害骰或孤注一掷。原书的孤注一掷选项保留。助力不消除大失败规则，100仍为大失败，原本96–100的低能力大失败范围也保留。

每次使用由服务端校验持有数量和最新修订号，并在同一事务内消耗道具、生成新结果和保存剧情。扣费依据服务端目录；客户端不能指定价格、奖励金额、目标值、骰点或原始状态。

结果窗口可前往商店，购买后“返回待确认的检定”；刷新、另一个设备或服务重启也能恢复未确认结果。点击“继续故事”确认后，这次检定不可再重掷。后续剧情行动也确认并关闭前一次窗口。

## 记录和兼容性

重掷取得新的修订号和新的历史记录。服务端使用保存的检定前状态重新结算，所以不会把原结果和新结果的生命／理智损失累加。原骰点与原历史保留，单独记录“已被重掷取代”的标记；历史／回放中会说明该结果不计入奖励。

购买使用请求 UUID；响应丢失时重试同一请求不会多扣点或多发道具。领取用账号＋成就 ID 的唯一约束；重掷和助力沿用游戏命令 UUID 的幂等机制。过期请求、无效动作、道具不足等失败会回滚整个事务。

数据库升级到 schema 3，新增钱包、库存、领取、购买和检定窗口表。升级不会修改原角色、骰点或进度。首次升级前备份数据库；旧 schema 2 程序拒绝打开 schema 3，因此跨这次升级回滚时需要兼容 schema 3 的程序，或在停服后按需恢复备份，不能只切换旧代码。

后端验证覆盖重复领取／购买、跨账号保护、金额伪造、余额不足、过期修订、重掷分支和伤害重算、服务重启恢复、助力范围与无效行动不消耗。浏览器验证覆盖桌面／手机的领取、购买、刷新后重掷与助力；真实模组路线验证仍在各模组测试文件中。
