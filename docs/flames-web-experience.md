# 《向火独行》网页内完整体验

新局默认使用 1.1.0 中文版，覆盖 270 个原书条目和 12 个规则辅助节点。默认编译同时保留已有《静躁独行》发布包；修订其规则需另发版本。1.0.0 的向火独行内容包保留，已有存档继续按原版本推进；玩家可新建中文版调查体验以下改动。

## 正文与操作

中文正文来自 `scripts/alone-against-flames/zh-CN/chapters`。HTML 被解析为纯文本，纸面指导块从玩家正文剥离；原始材料保留。游戏规则继续使用已审校的指令，而不执行来源 JavaScript。探索、职业、技能、仪式选项和检定标签使用中文；咒语原文、专有名词和原书地图标注保留，并提供中文说明。

“下一节”仍负责唯一的合法行动，但现在会提前说明本次检定、目标值或幸运骰。姓名在开局确定，年龄可选 23–36；属性分配说明八项属性含义，职业阶段列出职业、信用评级、必选技能与专长输入。记者和私家侦探的摄影、医生的拉丁语由职业规则固定，其他相关专长由玩家填写。后端校验点值、技能和专长，成功后一起保存。

局内地图从原始 EPUB 的 `emberhead_map.png` 提取。仅在条目 140 发现后展示，附中文地名说明，可放大，并随物品栏保存以便之后重访。文件来源和校验和在 `docs/assets-sources.json`。

## 结果与结局

幸运骰显示三颗 D6、点数之和与乘以 5 的公式。命令响应及历史保存完整点数；相同命令重试不再生成随机数。

战斗展示当前轮次、行动方、武器、护甲，以及双方个人骰点和成功等级。结算反馈明确区分命中、受到攻击、闪避和无人命中，附实际伤害。个人检定成功并不自动意味着对抗获胜：例如己方普通成功、对手困难成功时，弹窗显示对手命中和己方受到的伤害。结果会进入历史，音效按对抗结果播放。

施法界面显示可用魔法与生命、投入后的实际支付，以及每点 10% 成功率和 96–100 必败规则；提交按钮为“确认投入”。

三条常规生还路线分别保存为“骑向黎明”“走出烬头村”“劫后余生”，沿用各自正文和原书编号，并具有不同的结局收藏身份。其余终章使用中文名称。携带诗集时仍可选择研读后记。

## 验收

`tests/flames-experience.test.ts` 验证中文内容、地图发现范围与持久化、战斗反馈、职业专长校验、结局身份及幸运骰幂等历史保存。

`tests/browser/flames.full.spec.ts` 在桌面和手机执行五条完整路线：普通生还、施法结局、黑熊战斗后生还、发现并重访地图后生还，以及失败施法后的死亡。每条路线都通过实际 React 按钮完成开局、建卡和后续行动，中途刷新并核对存档，最后验证结局收集。测试调用真实 API handlers 和数据库，仅随机源受控，以可靠覆盖罕见失败；不提供生产环境跳关、状态修改或测试骰点接口。路线数据在 `tests/browser/fixtures/flames-routes.json`。

完整路线覆盖代表性分支，不能代替所有组合的规则审校。源文 262 的缺字等明确适配仍列在剧本包 `source.notes`。通用 CoC 职业扩展、冒险后成长阶段与其他模组的特殊规则不属于本次修改。
