# 阅读显示设置

在页面右上角打开“阅读偏好”。字号为 14–32px，字体为宋体与楷体，正文可选择中文或英文。中文可选择简体或繁体，转换在浏览器本地完成，不修改剧本、角色姓名或存档数值。

《向火独行》的 270 个原书段落以及适配的规则和结局节点均接入英文原文。英文取自仓库已有 EPUB，按照原书的指导文字样式去掉纸面操作和编号跳转。《静躁独行》的 1.0.0 提供兼容中文正文包，1.1.0 和 1.2.0 通过独立正文片段提供中文，修复原文排版断行；没有英文来源，目前仅支持中文及简繁转换；它的阅读设置会禁用英文选项。语言仅切换剧情正文和标题，操作界面保留中文。

文字出现方式包括直接显示、打字机和逐段浮现。打字机速度为 5–100 字/秒，段落间隔为 150–2000ms；默认直接显示。选择文字动画会启用完整动画模式。简化动画时直接展示全文。动画中可随时点击“显示全文”，也可以直接选择下一步。每个新剧情开始新的动画；同一剧情中的检定和填写不重播正文动画。切换字号或字体不重播动画。

动画预留全文高度，不因逐字或逐段显示而改变版面位置。屏幕阅读器可以直接读取完整文字，不逐字播报。回忆、回放和收藏也使用同样的字号、字体及语言偏好；长篇历史列表直接显示完整正文。

设置保存到当前浏览器的 `reading-options`。损坏的偏好恢复默认值，超出范围的数字会被限制到有效范围。默认宋体 20px、简体中文、直接显示。

## 语言包与存档

运行 `python3 tools/story/build_reading.py` 为《向火独行》的 1.0.0 和 1.1.0 生成 `reading.json`。这个包只包含各个节点的语言标题和正文，以及原文 SHA-256；不会改写已发布 `story.json`、规则和节点 ID。

运行 `python3 tools/story/build_static.py` 为《静躁独行》生成 1.1.0、1.2.0 片段内容包及 1.0.0 的兼容中文 `reading.json`，保持已发布的 1.0.0 规则文件不变。

服务器校验语言包的剧本 ID、版本和完整节点集合，每次仅提供当前节点的语言正文。读取旧回忆时，根据保存的节点标题与章节补充该节点的语言文本，不改写原历史。切换语言不提交命令，也不影响骰点、版本或进度。
