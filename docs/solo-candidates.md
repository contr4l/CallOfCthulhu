# KP-less 单人模组候选

检索日期：2026-10-12。范围为一名玩家、不需要 KP、有预写剧情的《克苏鲁的呼唤》模组；排除只支持一名玩家但仍需 KP 的 duet 模组、纯随机剧情生成工具，以及已经接入的《向火独行》《静躁独行》。

沿用免费获取的偏好：本轮没有核实到同时满足“免费完整版、真正单人 KP-less、有可靠高评分”的新增作品。下面的高评分作品作为备选资料，没有购买或导入。免费候选单独列出，未把收藏数当成评分。

## 未纳入

- Monophobia: A Fear of Solitude 和 Does Love Forgive?：一名玩家并不代表不用 KP；不按原生 KP-less 推荐。
- 選択死：作者页面写明 2PL，虽不需要 KP，但不是本次要求的单人模组。
- 31LOCKERs：曾限时免费，作者页面目前的完整版本收费；免费文件是注意事项图片。
- 准备好了吗？／もういいかい？：能找到中文 HTML 版本的作者说明线索，但本轮所见社区缓存评分为 6/10，未满足高评分筛选条件。
